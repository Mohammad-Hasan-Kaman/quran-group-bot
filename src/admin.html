مسیر Crisp (Cloudflare)

✅ Worker is ready! For this project, the bot is self-contained in a single Cloudflare Worker.

Admin Commands (/start /status /list /preview /setweek /skip /reset) work through Bale webhook.

To configure Cloudflare Workers:
  1. Go to cloudflare.com → Workers
  2. Create new Worker, copy src/index.js content
  3. Set KV Namespace in wrangler.toml
  4. Set Worker Secret BOT_TOKEN
  5. Deploy and configure webhook in Bale BotFather
